    recommended

    If your profile is public, poe.ninja lists your character together with its Path of Building code. Open your character on poe.ninja → Builds, copy the address from the browser and paste it here. After that, Refresh loads the latest state with one click.

    poe.ninja updates characters on its own schedule, usually every few hours. Changes you made in the last hours may not be there yet.

    Path of Building code

    Works always, also with a private profile: in Path of Building 2 import your character (Import/Export Build → Import from Path of Exile), then Export → Generate → Copy and click here. The clipboard is read once, only when you click.
