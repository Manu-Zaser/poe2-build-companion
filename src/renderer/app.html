Path of Building 2 file

always up to date

In Path of Building 2 click Items and Skills or Passive Tree and Jewels to import your character, then save with Ctrl+S. Choose the build here once – every save in PoB reloads it automatically. The file is only read on this computer; nothing is sent anywhere.

poe.ninja

If your profile is public, poe.ninja lists your character together with its Path of Building code. Open your character on poe.ninja → Builds, copy the address from the browser and paste it here. After that, Refresh loads the latest state with one click.

poe.ninja updates characters on its own schedule, usually every few hours. Changes you made in the last hours may not be there yet.

Path of Building code

Works always, also with a private profile: in Path of Building 2 import your character (Import/Export Build → Import from Path of Exile), then Export → Generate → Copy and click here. The clipboard is read once, only when you click.

Target

Use the Path of Building code of the build you follow, e.g. from a guide (Import code for Path of Building), or a build you saved in Path of Building 2. Each slot's item becomes a short list of target stats – the item check then shows whether a found item has them.

Your gear vs. the target

Values are the guide's rolls for orientation – an item counts as soon as it has the stat. Grey stats (rarity, light radius, …) are nice to have and do not count.

Hotkey

Combine with Ctrl or Alt, or use an F-key. Each press sends exactly one copy command to the game.

How it works

  1. Hover over an item in game and press the hotkey. The item is copied once and checked against your build in Path of Building.
  2. The overlay answers: better, worse or a trade-off, with the change in DPS of your main skill, effective HP, life and resistances – and warnings first, e.g. when a resistance falls below the cap or an attribute requirement is no longer met. Rings are checked in both slots.
  3. Equip in my build puts the item into the local copy of your build, without a new import. The character page shows how many items were changed since the last import.

The overlay stays open until you close it (× or Esc). Drag it anywhere – it remembers the position.
